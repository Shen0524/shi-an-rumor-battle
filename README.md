# 資安闢謠爭霸戰

一個可直接部署到 GitHub Pages 的互動式單頁遊戲。玩家要判斷常見安全迷思是真相還是謠言，選擇技能並擊敗謠言魔王。

## 本機開啟

直接用瀏覽器開啟 `index.html` 即可遊玩。

## 雙人配對

點選「建立雙人房間」後，第一位選手會產生 QR code。第二位選手掃描 QR code 即可加入同一場對戰，兩位選手會在自己的裝置上同題作答並互相攻擊。

開始方式：

1. 一號選手點「建立雙人房間」。
2. 二號選手用手機或另一台裝置掃描 QR code。
3. 畫面顯示「配對成功」後，不需要再按開始，兩位選手直接選技能並作答。
4. 兩位選手都作答後，系統會自動結算本回合。下一題由一號選手按「下一回合」。

雙人模式使用 PeerJS 建立瀏覽器之間的 WebRTC 資料通道，QR code 只用來傳遞配對連結。

## 賽後紀錄

每場遊戲會在本機瀏覽器記錄回合資料，包含題目、正確答案、選手答案、是否答對、使用技能、傷害、扣血、血量變化、分數與時間戳。

遊戲結束後可下載：

- JSON：保留完整 session 結構，適合程式分析。
- CSV：一回合一列，適合匯入 Excel 或 Google Sheets。

## 內容特色

- 10 題資安／資訊安全闢謠題
- 真相與謠言雙選判斷
- 事實光束、查證護盾、連擊破解三種技能
- QR code 雙人配對與即時對戰
- 賽後 JSON／CSV 紀錄匯出
- 血量、分數、連擊與動畫回饋

## 發佈

這是純靜態網站，可放在 GitHub Pages、Firebase Hosting 或任意靜態主機。
